# Qwen3-ASR 离线转写验证

本轮使用 Qwen3-ASR 0.6B int8，运行库为 `com.bihe0832.android:lib-sherpa-onnx:8.6.10`。模型不打进 APK，录音保留在原随口记中，失败可重试。

## 模型来源与导入

- [sherpa-onnx 官方模型说明](https://k2-fsa.github.io/sherpa/onnx/qwen3-asr/pretrained.html)
- [官方说明列出的 ONNX 仓库](https://modelscope.cn/models/zengshuishui/Qwen3-ASR-onnx/tree/master)
- 本地导入包：`.codex_tmp/models/qwen3-asr-0.6B-int8.zip`，约 941 MiB，只含配套六个文件；SHA-256 清单在同目录的 `qwen3-asr-0.6B-int8.sha256.json`。
- 手机传入 ZIP 原文件，在设置的「语音转写模型」导入，不必在手机解压。首次导入需留足约 2 GiB 可用空间（手机上的 ZIP + 解压模型），替换已有 Qwen 时还需要额外约 1 GiB 暂存空间。
- 设置显示「Qwen3-ASR 0.6B 已就绪」后重启应用再录音。完整 Qwen 导入并校验成功后自动清理旧 Paraformer；导入不完整或失败时保留原模型。已经导入 Qwen 的安装在下次转写前补清理旧模型，录音不受影响。
- ZIP 导入先在独立暂存目录完成路径、大小、完整性、分词器结构校验，再替换模型；导入错误保留原文件。上述是导入校验，不等同于已经在 Android 上完成模型推理验证。

## 手机测试

1. 普通话：「明天下午三点提醒我去人民医院复诊。」
2. 英文：「Remind me to call Alex at three tomorrow afternoon.」
3. 中英混说：「明天下午三点和 Alex 开会，讨论 API 的 deadline，地点在 Starbucks。」
4. 同一段里先中文再英文，核对英文未被翻译或音译，日期、金额和缩写正确。
5. 分别录制 5 秒、20 秒、45 秒，检查分段边界是否漏词、重复或截断。分段在末尾低能量位置切开，连续覆盖全部采样；当前没有独立 VAD，对背景噪声和无语音音频需特别验证。
6. 安静、日常背景噪声和长停顿各测一次，记录冷启动/再次转写耗时、内存、发热及失败情况。
7. 导入不完整或错误 ZIP 后，原模型仍可用。替换有效模型后，旧 Paraformer 专用模型目录应被清理，录音和随口记仍保留；下一次推理应加载新文件。

现有单次转写超时仍为 120 秒，长录音在手机 CPU 上可能超时；失败保留原录音，不宣称模型加载/耗时/准确率已通过真机验收。

## 胶囊回归

1. 保留一个日程胶囊，发起识别，进度变结果再消失：日程不重新弹出、不变排序。
2. 修改该日程的内容或时间：仅该胶囊更新；删除只取消对应条目。
3. 聚合取件、随口记提醒、图片挂起与识别结果并存，确认无关胶囊不重发。
4. 关闭/开启实况通知及系统撤掉通知后，确认可以正确恢复。
5. 小米超级岛：临时识别胶囊结束后恢复原日程，不重新触发首次浮出；新日程仍可首次浮出。厂商实际动画需对应 ROM 验证。
