# 首页日程视图验证

本轮只编译及运行本地单测；动画、手势和实际滚动位置需要用户自行打 Release 在真机验证。

## 入口和布局

- 今日页点击视图切换依次为日、周、月、日程；长按可直接选“日程视图”。
- 左侧为星期、日期、农历，选中日期和农历使用圆角矩形背景，今天未选中时只突出文字；右侧为当天支出及日程卡片。摘要和卡片随日期留白分组。
- 同一天日期与支出只显示一次，卡片继续沿右侧排列；金额可点击进入对应日期账单。
- 无消费显示“暂无消费记录”；仅有账单的日期仍显示，无日程且无账单的日期跳过。
- 无重复日程时，最后一条实际记录就是列表终点。

## 连续性

1. 月视图选一个有数据的日期，切到日程视图：首次显示就定位到该日；选中空日期则定位最近有内容日期。
2. 日、周、月切入日程以及返回：可见的选中背景应连续移动、缩放和改变圆角，日期文字不能被背景遮住；连续快速反向切换不能闪白、排队播放或出现过时内容。
3. 日程列表滚到中间，搜索其他日期的日程；清空搜索后应恢复原视图和滚动位置。
4. 搜索时输入/清空、返回时，退出动画不应短暂显示全部结果。
5. 无限重复首次只展开今天及未来七天；到列表底部上滑并松手，增加七天后原卡片应保持位置。
6. 开发者 → 日程视图 → 向上排列：日期由晚到早，同日时间仍由早到晚；到顶部下拉加载后续七天，原卡片不能被挤走。
7. 仅滑到末端而未继续拖动时不自动反复加载；后续确实没有实例时显示“没有更多日程了”，不再提供加载按钮。
8. 加载后继续查看新日期，不能因为加载按钮移动而直接跳到新窗口的末端。
9. 加载提示相对整个列表居中，不能沿右侧卡片栏缩进；正向位于底部，反向位于顶部。
10. 拖动时进度环缓慢浮现，松手达到阈值后转圈，加载完成淡出；未达阈值松手仅收回，不追加数据。
11. 每月重复等稀疏日程，本次七天无新增但更远还有实例时提示“这 7 天暂无日程”，仍可继续加载，不能误报没有更多。
12. 列表滚动后离开日程视图，离场内容保持原滚动位置；选中日期仍在屏幕内时检查反向共享动画。

## 内容与操作

- 搜索未归档的历史日程和三个月后的单次日程，均可找到；不因隐藏全部列表页而失效。
- 搜索无关关键词时，不保留只有账单的日期来制造假结果；只在匹配的无限重复还有后续时提供加载入口。
- 编辑、长按、侧滑归档等操作沿用原日程卡片。无限重复中的已修改子事件不应重复显示。
- 用较大字体、窄屏及横屏检查日期栏、长标题、金额换行和卡片侧滑按钮。

相关单测为 HomeAgendaTest，并回归 AllEventsConnectorTest、RepeatOccurrenceCalculatorTest 和 AccountingPreviewDataTest。

## 日视图顶栏圆角衔接

- 日程视图返回日视图时，选中块上方圆角逐渐衔接日期卡片的上圆角，下方圆角逐渐收为平直边；到位前后不能突然多出或裁掉两个直角。
- 检查反向切换以及移动途中快速切换回日程视图；今天、非今天、浅色/深色和壁纸背景都应保持轮廓连续。
