# Will do 博客示例源

这是协议 v1 的最小文字示例，正文提取和手机端摘要生成已于 2026-10-09 得到用户验证。访问作者自有博客 `aixinjueluoonline.top`，提取文章标题、作者和正文。它是独立的源包，不内置到 APK；不提供其他平台的解析实现。

## 手机测试

1. 运行下面的打包命令，把生成的 ZIP 传到手机。
2. 打开 Will do → 实验室 → 链接解析 → 导入源，选择 ZIP。
3. 收藏 [will do 操作手册](https://aixinjueluoonline.top/posts/will-do-manual/) 这条文章链接。首页是列表，不能当文章链接使用。
4. 已开启「自动生成摘要」时，新收藏会按现有流程分析；否则在详情页菜单中手动生成。已有记录需要手动生成／重新生成。
5. 确认摘要保存到原随口记，完成通知可以打开对应详情。

**应用目前只有一个源槽位，导入会替换现有源。测试前请保留原源包，方便重新导入恢复。** 生成摘要仍需要配置在线 AI；文章标题、正文等信息会发送到该服务。

## 文件与打包

- `manifest.json`：版本、入口、链接匹配和网络权限。
- `main.js`：带注释的 `extract(input, host)`，演示 HTTP、正文提取及结构化成功／失败返回。
- `package.py`：用 Python 标准库打包，ZIP 根目录只有 `manifest.json` 和 `main.js`。
- 本说明、打包工具和任何测试 HTML 均不进入 ZIP。

在仓库根目录运行：

~~~powershell
python examples/link-sources/willdo-blog/package.py
~~~

输出：`build/link-source-examples/willdo.blog-example-v0.1.0.zip`。修改源码后重新打包；正式更新时同步增加 manifest 的 version，再重新导入。

## 访问边界与提取规则

- 清单仅允许精确域名 `aixinjueluoonline.top`，没有通配符或其他域名。
- 只匹配 `/posts/` 下的文章，脚本会检查文章路径和跳转后的目标。
- 不申请浏览器、登录或请求重放权限；不读取随口记正文。
- 定位博客的 `markdown-content` 正文区域，去掉脚本、样式与标题锚点，保留章节、列表、表格单元格和图片说明的文字。
- 不下载图片或音频；有图片的文章会返回文字提取限制说明。页面结构变化、正文缺失或请求失败会明确报错，不把导航／页脚拼成正文。
- 这是针对该博客模板的简单提取器，不是通用 HTML 解析库。

未修改的发布包只访问这个博客。用户修改清单和代码后可开发其他源，需自行确认访问和使用权限；宿主仍按导入源所声明的权限检查网络请求。只导入可信源。
