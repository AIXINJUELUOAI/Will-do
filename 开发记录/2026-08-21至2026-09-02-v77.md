# 2026-08-21 至 2026-09-02 开发记录（v77）

## 概述

本阶段在上一份记录（2026-08-19 至 2026-08-20，v76）基础上，重点完成模型连接流程修复和第三方 Agent 接入。Willdo 现在同时保留面向官方 Agent 的完整 ContentProvider 接口，并为 Eta 等具备普通 Shell 能力的第三方 Agent 提供无需 Root、Shizuku、ADB 或相同签名的广播入口；第三方访问由独立开关控制，并明确限制附件和文件操作。

当前构建版本：

- `versionName = 2.3.0`
- `versionCode = 116`（v76 记录时为 113）
- `minSdk = 33`
- `targetSdk = 36`

## 1. 模型连接流程修复

- 重做模型配置的“连接 → 获取模型 → 选择/填写模型 → 保存”流程，连接成功前不再保存无效配置。
- DeepSeek、OpenAI 和 Gemini 预设服务商改为请求各自的真实模型列表接口，不再依赖写死的模型名称。
- 成功获取模型后仍在当前卡片内向下展开完整列表，不弹出额外 Sheet。
- 连接成功但模型列表为空时，将模型选择栏切换为可编辑输入栏，允许用户手动填写模型名称。
- 服务端返回 `404`、`405` 或 `501` 时，按“连接可用但不支持模型列表接口”处理，并进入手动填写模式。
- 网络、鉴权或其他真实连接错误会直接提示“连接失败”，不会保存配置。
- OpenAI 兼容地址的模型列表 URL 归一化逻辑支持已有 `/models` 地址，避免重复拼接路径。
- 本阶段继续保持 OpenAI 兼容格式；未新增 Anthropic 协议格式适配。

## 2. 第三方 Agent 普通 Shell 接入

- 新增导出的 `WillDoAgentReceiver`，接收 `com.antgskds.calendarassistant.AGENT_CALL` 广播。
- 第三方 Agent 可直接通过普通应用身份执行 `am broadcast` 调用 Willdo，不需要 Root、`su`、Shizuku、ADB 或相同签名。
- 广播接收器只负责传输适配，实际请求解析、权限判断、方法分发和返回 JSON 仍复用 `WillDoAgentProvider`，避免形成两套业务实现。
- 官方 Agent 继续通过受签名权限保护的 ContentProvider 调用，保留完整能力和原有安全边界。

## 3. 新增第三方访问开关

- 在“允许 Agent 访问”展开区域新增“允许第三方 Agent 访问”开关。
- 开关说明为“允许第三方 Agent 访问、操作 WillDo 数据”，默认关闭。
- 总开关关闭时所有 Agent API 均不可用；总开关打开但第三方开关关闭时，广播入口返回 `THIRD_PARTY_DISABLED`。
- 配置项同步加入 `MySettings`、`SettingsViewModel` 和 `ConfigCatalog`，可随设置正常持久化。
- 连接管理和数据库操作仍受各自子开关控制，第三方 Agent 无法绕过现有权限设置。

## 4. 官方与第三方能力分级

- 官方 Agent 保留全部 47 个 API 方法，包括附件、图片、语音、诊断日志导出和备份导出。
- 第三方 Agent 开放 39 个非文件 API，覆盖日程、重复日程、课程、文字随口记、设置、连接、同步、天气、数据库和系统信息。
- 第三方通道禁用以下 8 个文件相关方法：
  - 日程附件添加、查询、删除。
  - 随口记图片添加、移除和语音添加。
  - 诊断日志导出和备份导出。
- 创建或修改请求如果夹带附件、非文字随口记媒体等受限内容，也会返回 `UNSUPPORTED_TRANSPORT`，防止绕过方法白名单。
- `getCapabilities` 会根据调用通道返回对应方法列表；第三方通道的 `supportsContentUriFiles` 为 `false`。

## 5. 配套 Willdo Skill

- 完成面向 Eta 的 `manage-willdo` Skill，包含协议、日程、课程、随口记、设置、连接、同步、数据库和完整接口测试说明。
- Skill 明确要求直接使用普通 Shell，不主动尝试 Root、Shizuku、ADB 或 `content call`。
- 增加数据来源优先级规则：用户询问“今天有什么日程”“明天有什么安排”等普通问题时，优先查询 Willdo；只有用户明确指定系统日历时才查询系统日历。
- 安装包采用扁平 ZIP 结构，所有 Markdown 文件均位于 ZIP 根目录，避免 Eta 的“不安全文件路径”拦截。
