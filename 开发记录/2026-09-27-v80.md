## 1. 图片挂起与多图追加

- 实验室新增默认关闭的“图片挂起”开关，开启后提供系统图片分享目标及桌面长按快捷选图入口。
- 支持单图分享、多图分享和系统多选图片；再次分享或选图会追加到现有挂起组，不替换已有图片。
- 所有挂起图片共用一个胶囊。单张时小胶囊显示“图片挂起”，多张时显示“共 X 张”；展开后保留功能名称和查看提示。
- 点击胶囊复用已有媒体悬浮弹窗，通过左右滑动切换图片并显示页码，不另建图片浏览器或增加依赖。
- 原生实况通知、Flyme 和小米超级岛沿用已有发布链路，携带图片挂起的查看与结束操作。
- 分享目标、快捷入口和通知图标统一改为 Image 方框山形图标；分享入口与通知分别保留适用的深色和白色资源。
- 图片挂起独立于日程、随口记和记账，不调用 AI，不创建这些业务记录。

主要实现：[ImagePinController.kt](../app/src/main/java/com/antgskds/calendarassistant/feature/imagepin/ImagePinController.kt)、[ImagePinHandleActivity.kt](../app/src/main/java/com/antgskds/calendarassistant/platform/entry/image/ImagePinHandleActivity.kt)、[FloatingMediaCardConnector.kt](../app/src/main/java/com/antgskds/calendarassistant/platform/floating/ui/connector/FloatingMediaCardConnector.kt)。

## 2. 本地存储、兼容与清理

- 外部图片复制到应用私有目录 `files/image_pin/`；SharedPreferences 保存当前挂起标识及有序图片列表。
- 兼容旧单图格式：只有旧 `id`、没有图片列表时，仍可恢复该图；后续追加时保留旧图并写入新列表。
- 整批新增图片复制和解码校验成功后才更新索引。复制、校验、容量检查或索引提交失败时清理本批副本，保留原有挂起图片。
- 数量与容量上限集中登记在 [ConfigCatalog.kt](../app/src/main/java/com/antgskds/calendarassistant/shared/management/catalog/ConfigCatalog.kt)：最多 20 张，单张 16 MiB，合计 128 MiB。超过限制时提示，不自动淘汰旧图。
- 点击“结束挂起”会关闭胶囊、清空整组挂起索引并删除全部挂起副本；不会删除相册或其他应用中的原图。
- 关闭实验室“图片挂起”开关也会清理全部挂起副本。仅关闭实况通知时隐藏胶囊，保留图片，重新开启后可以恢复展示。
- 启动恢复时清理未被当前有效图片列表引用的副本。截图使用的临时 PNG 在正常处理完成或异常退出该流程时清理。
- 当前没有按小时、当天结束或其他时间规则自动清除已挂起图片的功能；重启应用不代表结束挂起。

## 3. “截图挂起”快捷设置磁贴

磁贴名称确定为“截图挂起”，使用同一 Image 图标。用户可在系统快捷设置编辑页添加。

点击后的流程为：必要时解锁 → 检查功能与权限 → 收起控制中心 → 等待已有截图延迟 → 无障碍截图 → 追加到现有图片挂起组。

- 复用无障碍截图回调和用户配置的截图延迟，不调用识别模型，不依赖模型配置。
- 使用既有截图/识别忙碌标记，避免连续点击及并发识别争抢截图；支付诊断期间提示先结束诊断。
- 要求图片挂起和实况通知开启、悬浮窗权限可用、本应用通知与实况渠道未被关闭。点击和采集流程中重新核实条件。
- 无障碍服务不可用时复用已有恢复工具；仍不可用则引导至无障碍设置，用户返回目标页面后重新点击磁贴。
- 截图前后检查锁屏状态，截图前检查活动窗口是否仍为 SystemUI；检测到系统面板未收起时提示重试，不继续保存该次截图。
- 系统拒绝截图、截图超时或保存失败时提示失败，保留原有挂起图片。受保护页面仍受 Android 截图限制。
- 截图以临时 PNG 接入与外部分享相同的追加、容量限制和失败清理逻辑；已有图片数量与胶囊文案随成功追加更新。
- 新入口和流程已登记至 `FeatureCatalog`、`PipelineCatalog`，截图挂起的开关与权限判断归入 `ImagePinPolicy`。

主要实现：[ImagePinTileService.kt](../app/src/main/java/com/antgskds/calendarassistant/platform/tile/ImagePinTileService.kt)、[TextAccessibilityService.kt](../app/src/main/java/com/antgskds/calendarassistant/platform/accessibility/TextAccessibilityService.kt)、[ImagePinPolicy.kt](../app/src/main/java/com/antgskds/calendarassistant/feature/imagepin/ImagePinPolicy.kt)。

## 4. 同次提交的分享与无障碍调整

- 图片分享中转使用透明、无预览、无进出动画的主题，避免中转窗口影响体验；图片随口记分享入口使用独立图标。
- 系统分享目标“识别为日程”改为“识别信息”，图片分享 Worker 通过 `recognitionApi` 契约发起识别。
- 无障碍 XML 和连接基础 flags 固定启用交互窗口读取与 View ID 报告，按键过滤仍独立管理。
- 支付诊断启动和结束不再通过回调切换无障碍 flags；诊断说明与基础 flags 测试同步调整。
- 上述无障碍配置调整已随代码提交保存，但不能据此认定所有 ROM 或支付应用的间歇失效已经解决。
