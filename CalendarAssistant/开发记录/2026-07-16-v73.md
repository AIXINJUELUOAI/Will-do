# 2026-07-16 实况手环模式与备份导出修复

## 本次调整范围

本次是在开始 MIUI/HyperOS 风格开发前的一组小调整，目标是先把当前主线体验问题收口，避免后续 UI 开发时混入功能修复。

## 具体改动

### 1. 实况胶囊通知默认开启

- 将 `MySettings.isLiveCapsuleEnabled` 默认值从 `false` 调整为 `true`。
- 将旧版 SharedPreferences 迁移时的 `live_capsule_enabled` 兜底默认值同步调整为 `true`。

影响：

- 全新安装用户默认启用实况胶囊通知。
- 已有用户如果已经保存过设置，不会被强制覆盖，仍以现有配置为准。

### 2. 实验室新增手环模式

新增设置项：

```kotlin
braceletModeEnabled: Boolean = false
```

实验室页面新增“手环模式”开关。

开启后：

- 日程实况胶囊提醒触发时，不再完全压制普通通知，而是额外发送一条普通通知镜像，便于手环同步。
- 天气预警、天气风险预测以实况胶囊展示时，也额外发送普通通知镜像。
- 普通通知镜像使用独立 `notificationId`，避免覆盖原本的实况通知/胶囊展示。

暂未扩展到 OCR、随口记进度等短暂胶囊，避免把进度类状态也同步到手环造成干扰。

### 3. 备份导出附件失败修复

排查发现 ZIP 备份导出时，只要附件、随口记录音、随口记图片、背景图片中的某个文件路径异常或不可读，就可能导致整包导出失败。

本次修复：

- 导出前只纳入真实存在、是普通文件、且可读的文件。
- ZIP 写入单个文件失败时跳过该文件并记录日志，不再让整个备份导出失败。
- 附件、随口记录音、随口记图片、应用背景图统一走同一套容错写入逻辑。
- 增加 `BackupCoordinator` 诊断日志，导出时会记录开始/成功/失败、各类文件数量，以及被跳过文件的分类、归属信息、路径和可读性状态。
- 针对 ColorOS 文件管理器返回的导出目标 URI 可能无法用默认方式打开的问题，目标输出流改为按 `wt`、`w`、默认模式依次尝试，并分别记录打开结果。
- 根据后续日志确认，目标输出流实际已能用 `wt` 成功打开；真正失败原因是 `use { ... } ?: error("无法打开导出文件")` 将 ZIP 写入 lambda 的返回值误当作打开结果。没有应用背景图时，最后一行 `backgroundExportItem?.let { ... }` 返回 `null`，触发了错误提示。本次改为先显式获取 `OutputStream`，再执行 `use` 写入，避免因写入代码块返回值误报导出失败。

效果：

- 某张随口记图片或某个附件丢失/不可读时，备份仍可导出。
- 可读文件继续正常进入 ZIP。
- 不可读文件不会拖垮整个备份流程。

### 4. 主页日期卡左右滑连续切换修复

修复主页日期卡左右滑只能切换一次、再次滑动无响应或跳回“今天前后一天”的问题。

原因：

- 日期卡手势使用 `pointerInput(Unit)`，手势回调捕获的是首次进入页面时的 `selectedDate`。
- 页面日期变化后，手势回调没有拿到最新日期，后续滑动仍然基于初始日期加减一天。

修复：

- 将手势监听 key 调整为 `state.selectedDate`。
- 增加拖动取消时的累计滑动距离重置。

效果：

- 日期卡可以连续左滑/右滑切换日期。
- 每次切换都基于当前显示日期继续计算，不再卡在初始日期附近。

### 5. 备份选项语义调整：附件归入日程，随口记文件归入随口记

根据后续讨论，备份界面不再把“附件”作为独立选项展示，避免用户误解为附件和日程可以分开恢复。

调整后语义：
- 勾选“日程数据”时，自动包含日程附件。
- 勾选“随口记”时，自动包含随口记文本、状态、录音和图片。
- `AppBackupOptions.includeAttachments` 字段保留，用于兼容旧备份和旧调用路径，但内部会归一化为跟随 `includeEvents`。
- 如果旧调用传入 `includeAttachments=true` 但 `includeEvents=false`，仍会自动补上日程数据，保证附件恢复时能找到对应日程。

导出格式同步调整：
- 选择日程或随口记时走 ZIP，因为这两类数据现在可能包含文件。
- 仅选择设置、提示词等纯文本数据时仍可走 JSON。

界面同步调整：
- 数据备份入口描述去掉独立“附件”分类。
- 备份选项页移除“附件”开关。
- “日程数据”说明中显示日程附件会随日程一起处理；导出时如本机存在附件，会显示附件数量。
- “随口记”说明改为包含文本、状态、录音和图片。
