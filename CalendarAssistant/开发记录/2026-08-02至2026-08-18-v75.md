# 2026-08-02 至 2026-08-18 开发记录（v73）

## 概述

本阶段在 `2.3.0` 主线上继续完善 Will do 的外部 Agent 能力、彩云天气接入、取件码识别和大屏自适应体验，同时统一了主页、设置、日程、随口记、便签与组件配置页的交互样式，并补充权限治理、诊断日志脱敏和相关测试。

当前构建版本：

- `versionName = 2.3.0`
- `versionCode = 112`
- `minSdk = 33`
- `targetSdk = 36`

## 1. Will do Agent 跨进程数据接口

- 新增 `WillDoAgentProvider`，通过 ContentProvider 向官方 Agent 应用提供受控的数据访问入口。
- 新增签名级权限 `com.antgskds.calendarassistant.permission.AGENT_API`，仅允许相同签名应用调用。
- 新增 Agent 协议、数据服务、数据库服务、JSON 编解码和统一错误响应，覆盖日程、随口记、便签、设置与连接配置等数据能力。
- 新增 `AgentDataApi` 写操作契约，并通过既有 facade、query 和 operation 接口访问业务数据，避免 Provider 直接穿透到 UI 或数据库实现。
- 在 AI 设置页增加“允许 Agent 访问”和“允许 Agent 管理连接配置”开关，默认关闭，由用户显式授权。
- 将 Agent 能力登记到 Feature、Config、Helper 和 Pipeline Catalog，并增加协议、事件查询、权限目录和 Provider 行为测试。
- 为 release 混淆配置补充 Agent Provider 与协议模型保留规则。

## 2. Agent 诊断日志与隐私保护

- 新增 `DiagnosticLogRedactor`，在导出 Agent 诊断包前统一处理 Token、API Key、Authorization、Cookie、URL 用户信息及常见凭据字段。
- Agent 日志导出支持最近 5、30、60 分钟范围，并明确限制可用时间窗口。
- 日志输出只保留排障所需信息，减少连接配置和用户隐私泄露风险。
- 补充日志脱敏单元测试。

## 3. 彩云天气正式接入

- 在原有和风天气之外新增彩云天气 Provider，加入 `CaiyunWeatherAdapter` 和独立 Provider Client。
- 支持彩云实时天气、逐小时/逐日预报、空气质量和天气预警数据到统一天气模型的转换。
- 天气设置页支持 Provider 切换，并分别保存和风天气与彩云天气的 API 地址和凭据，切换时不覆盖另一供应商配置。
- 对彩云请求地址、Token 路径和错误信息进行归一化，避免底层异常直接暴露敏感信息。
- 更新彩云天气开发计划，记录当前实现状态和后续事项。
- 补充天气适配器与请求行为测试。

## 4. 取件码与剪贴板识别链路调整

- 移除常驻的 `ClipboardCodeMonitorService` 及 `FOREGROUND_SERVICE_SPECIAL_USE` 权限，不再依赖特殊用途前台服务持续监听剪贴板。
- 将剪贴板检查收敛到应用进入前台和无障碍入口，在系统允许读取剪贴板的时机执行识别。
- 重构 `InstantCodeParser` 和匹配规则，增强取件、取货、提货、取餐、取票和寄件场景识别。
- 识别结果继续通过统一 Recognition/Ingest 链路生成日程，避免入口自行写库。
- 调整实验室设置文案，使行为描述与新的前台检查机制一致。
- 增加即时码解析测试，覆盖误识别和边界文本。

## 5. 大屏、折叠屏与桌面模式自适应

- 引入 AndroidX Window，并新增统一的 `AdaptiveLayoutInfo`、`LocalAdaptiveLayoutInfo` 与窗口姿态检测。
- 新增 `AdaptiveTwoPaneLayout`，为列表/详情、设置导航和桌面组件配置提供统一双栏容器。
- 主页新增 `AdaptiveHomeNavigationRail`，宽屏下使用常驻侧边导航，窄屏继续使用底部导航。
- 支持折叠设备 tabletop 姿态，并根据窗口宽度、分割区域和导航形态调整页面布局。
- 主页、全部日程、课程管理、设置、天气详情、随口记、便签和 Widget 配置页接入自适应布局。
- 增加自适应布局策略测试。

## 6. 主页与日程界面完善

- 重构主页日期区、天气区、日程列表和空状态布局，统一卡片间距、圆角与内容层级。
- 优化主页浮动操作栏及宽屏导航协作，避免与双栏内容和系统区域冲突。
- 全部日程页接入双栏布局，完善日期分组、筛选、空状态和事件详情交互。
- 统一事件滑动操作、添加日程弹窗和课程管理弹窗的组件样式。
- Schedule facade 补充 Agent 和 UI 所需的统一日程操作能力。

## 7. 设置、引导页与权限治理

- 重构设置详情页与侧边栏，在宽屏环境使用常驻导航，并统一设置项、滑块、标题和说明文字样式。
- 新增 `SettingsSliderTypography`，统一滑块类配置项的数值和辅助文本排版。
- 完善初始化引导页权限管理：Root/Shizuku 可用时支持单项开关和一键授权，并保持普通设备的系统设置跳转路径。
- 新增 `PrivilegedPermissionController`，统一通知、悬浮窗、麦克风、日历、精准闹钟、电池优化、定位、无障碍、通知监听和短信权限状态及授权操作。
- 开发者页、实验室、偏好设置、主题、壁纸、天气和 AI 设置页同步统一组件与交互反馈。

## 8. 公共 UI 与页面体验统一

- 调整 `AppUiComponents`、`FloatingActionCard`、`PredictiveFloatingActionCard` 和设置行组件，使各功能页复用同一套 Will do 视觉语言。
- 优化壁纸编辑器的预览、裁切与操作布局。
- 统一随口记列表、详情页、便签编辑器和顶部操作区。
- 优化课程、天气、捐赠和桌面组件配置页面的间距、排版及窗口适配。
- 版本号提升至 `versionCode = 112`。

## 9. 测试与架构约束

新增或补充测试覆盖：

- Agent Provider 协议、JSON 编解码、事件查询和访问配置。
- Agent 诊断日志脱敏。
- 彩云天气数据适配与错误处理。
- 即时码/剪贴板识别。
- 自适应布局策略。
- Config Catalog 的 Agent 权限登记。

本阶段新增能力继续遵循 Catalog 登记和统一 API/facade 边界，避免外部入口直接依赖 Repository、DAO 或具体 UI 实现。
