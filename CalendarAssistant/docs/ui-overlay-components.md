# 公共弹层、滚轮与悬浮操作

不增加大中小尺寸档位或用户设置。Sheet 的标题、操作区与安全区统一，正文由业务自由组织。

## Sheet 统一入口

`shared/ui/material/component/AppModalBottomSheet.kt` 是唯一 Sheet 容器实现，已在 `HelperCatalog.kt` 登记。`EditionModalBottomSheet` 仅转发相同的标题、操作模型，不维护另一套布局。

- `title`：必填，左对齐 `titleLarge` / Medium；顶部居中拖动条。
- `subtitle`：可选，统一 `bodyMedium` / `onSurfaceVariant`。长说明放正文，避免固定标题区占满小屏幕。
- `content`：业务内容插槽。默认只滚动正文，标题和操作区固定；公共容器负责左右 20 dp 与正文底部 16 dp 留白。
- `actions`：0～3 个 `AppSheetAction`。业务传文字、回调、enabled 和 Primary / Secondary / Destructive 类型。
- `scrollState`：默认由公共组件创建。业务正文已有 `LazyColumn` 等滚动容器时显式传 `null`，并确保列表在剩余高度内测量，不再套第二层纵向滚动。
- `sheetState`：可选；默认跳过半展开状态，短内容自然展开，长内容受可用高度限制。

不再提供任意 `bottomBar` 插槽。业务不能重复添加标题、保存/取消按钮、系统栏 padding 或额外的底部背景。

## 操作区规则

| 操作数 | 布局 |
|---|---|
| 0 | 不创建操作区，不保留按钮占位，仍避让导航栏 |
| 1 | 一行撑满 |
| 2 | 同一行左右等宽 |
| 3 | 第一个在上方撑满，第二、三个在下方等宽 |

按钮顺序由列表顺序确定。常规双按钮左次右主；删除使用错误容器色。按钮最小高度 52 dp、圆角 16 dp、间距 12 dp，操作区左右 20 dp、顶部 8 dp、底部 20 dp；大字体允许按钮自然增高。

```kotlin
AppModalBottomSheet(
    title = "示例",
    onDismissRequest = onDismiss,
    actions = listOf(
        AppSheetAction("取消", onDismiss, role = AppSheetActionRole.Secondary),
        AppSheetAction("保存", onSave, enabled = canSave),
    ),
) {
    // 只写业务正文；触感与保存校验仍由业务回调负责。
}
```

## 高度、材质与动画

- 顶部圆角 28 dp；高度随内容自然变化，最大高度扣除顶部安全区、24 dp 顶部间距和键盘占用，避免长列表默认顶到屏幕上沿。
- 标题、正文、操作区及导航栏安全区属于同一个连续材质表面。普通/玻璃模式使用完全相同的布局。
- 材质放在原生 Sheet 位移内部，操作区不单独动画，不重复绘制背景或分隔线。`SheetMaterialSurface` 将背景与正文分层：背景按原生 Surface 的实际坐标范围绘制，正文保留原生预测性返回的等比缩放。
- Material3 1.4 的内容 Column 会额外压缩 Y；背景单独抵消这一变换，也抵消回弹时正文的反向缩放，避免底部露空。通过 `onGloballyPositioned` 跟踪实际变换，不复制私有进度或动画参数，不增加底部占位。外层不裁切到正文高度，最终由原生 Surface 裁切。
- 当前材质适配依赖 `原生 Surface → 原生内容 Column → SheetMaterialSurface` 的直接父布局关系；升级 Material3 时复核这一关系。背景采样父场景，子弹窗采样本 Sheet，避免循环采样。
- 保留 Material Sheet 的拖动、返回与外部点击关闭。点击拖动条收起，等待隐藏动画结束再通知业务移除。
- 独立窗口关闭导航栏对比度遮罩并使用透明导航栏/分隔线，图标亮暗随面板底色；系统安全留白放在材质内部。
- `LocalAppPageBottomPadding` 在 Sheet 内重置为 0，避免继承页面导航栏留白。

`AppWindowBackdrop` 使用屏幕坐标对齐源和目标，合成父场景，处理平移/缩放及模糊降采样。新跨窗口背景继续使用 `rememberAppWindowBackdrop` / `Modifier.appWindowBackdrop`，不要直接将局部 `LayerBackdrop` 交给另一窗口。

## 滚轮与悬浮按钮

- `AppWheelPicker.kt`：保留原有 `WheelPicker` 等函数入口、175 dp 高度、35 dp 行高及吸附/触感；日程、课表、作息表、偏好、随口记与悬浮日程复用。轮子本身不增加第二层玻璃。
- `AppFloatingActionButton.kt`：课表、作息表独立按钮；首页组合栏复用 `AppFloatingActionSurface`。保留 72 dp 按钮、34 dp 图标，无尺寸档位。
- 普通单击保留原生反馈，可选长按使用 `combinedClickable`；不向原有按钮新增长按行为。业务负责触感，公共组件不重复触发。

## 验证与实机复核

本轮执行 Kotlin PSI 语法解析、调用点检查及 `git diff --check`。按用户自行构建的约定，未运行 Gradle、架构守卫或装机；语法解析不检查 Android/Compose 类型依赖，不能替代编译。

实机重点：来源日历与提醒的标题/按钮是否一致，长列表顶部间距与保存按钮位置，开关/拖动/回弹动画，导航栏区域和玻璃覆盖，提醒滚轮展开，颜色输入键盘，横屏及大字体。玻璃渲染与动画是否彻底解决需要实机确认。

## 公共锚点菜单

`AppDropdownMenu.kt` 提供 `AppDropdownMenu` 与 `AppMenuItem`，已登记 `HelperCatalog`。今日右上角视图切换与宽屏更多操作均已接入。

菜单与触发按钮放在同一个 `Box` 中，公共组件通过独立 `Popup` 窗口定位；不再由页面保存根布局坐标并手动叠加菜单。统一 208 dp 宽度、24 dp 圆角、选中标记、禁用/危险状态、进出动画、超长菜单滚动、边界避让，以及返回和外部点击关闭。操作先关闭菜单再执行业务回调，业务保留短按/长按语义与触感。

玻璃回归路径：原今日菜单是首页窗口中的内联覆盖层。`homeSceneBackdrop` 新增父 `appSceneBackdrop` 后，菜单采样会访问包含菜单自身的 Activity 场景，形成图层循环依赖。新菜单在 Popup 窗口内绘制，Activity 场景只记录触发按钮和页面，避免记录菜单自身；继续使用现有跨窗口玻璃采样，未关闭玻璃效果。

`AppDropdownMenuTest` 覆盖普通/玻璃模式的短按、长按展开、选择关闭及返回关闭；玻璃用例包含父场景与局部场景两级采样。当前未连接测试机，未运行这些仪器测试，构建与实际崩溃修复效果仍待验证。

## 公共分段切换

`AppSegmentedControl.kt` 已登记 `HelperCatalog`。主题的预设/自定义、小组件类型、小组件预览尺寸、小组件主题，以及底栏编辑默认启动页共 5 处，全部使用这一入口。

业务传 `options`、`selectedOption`、`label` 与 `onSelected`，选项值保持唯一和稳定；不重复实现按钮背景、字号、颜色动画或触感。选中项统一采用当前 `MaterialTheme.colorScheme.primary` / `onPrimary`，沿用底栏编辑的主题主色；未选中项透明，底板通过 `AppGlassSurface` 统一适配普通与玻璃模式。

统一外圆角 14 dp、选项圆角 10 dp、外留白 6 dp、选项间距 4 dp；等宽、等高，最小触摸高度 48 dp，大字体可换行撑高。颜色平滑过渡，选中项加粗，单选语义与禁用状态由公共组件提供。只有切换到其他选项时触发一次选择触感和业务回调。

这轮完成静态语法、5 处调用与差异检查；未构建装机。实机检查主题色变化、普通/玻璃模式、四选项布局及默认启动页保存。

## 设置分隔线、设置行与列表侧滑

- `AppSettingsDivider` 统一设置卡片内的 16 dp 水平缩进、0.5 dp 线宽及主题颜色。AI、日程、偏好、天气、小组件设置已接入；开发者页和配置编辑页本轮保留。
- 实验室的「取件类事件使用当前时间」「剪贴板取件类识别（Beta）」「预测性返回手势」「手环模式」接入现有 `SwitchSettingItem`，卡片补充垂直留白以保留原有间距。引导页复用相同实验室内容，也随之接入；权限及持久化仍由业务处理。
- `AppSwipeReveal` 统一向左拖出动作区、回弹、取消、外部收起及阈值触感；前景根节点必须使用组件传入的 `Modifier`，动作完成时调用 `close`。动作区保持完整宽度，按实际露出宽度裁切；容器透明，不新增玻璃采样或背景。
- 日程和课程保留 50% 展开阈值；随口记保留 28% 展开、50% 拖动触感阈值、32 px 额外拖动空间及原弹簧参数。按钮尺寸、动作与语音播放按钮淡出由业务保留。阈值触感不在同一次越界及松手时重复触发。
- 浮窗中含双向、全滑执行的条目不属于本次单向展开迁移；笔记工具栏不迁移。
- `AppSwipeRevealTest` 覆盖不同阈值、外部收起、更新后的回调及拖动取消。按自行构建约定，仪器测试未运行，需实机复核列表侧滑、纵向滚动、长按、动作按钮与普通/玻璃主题。
