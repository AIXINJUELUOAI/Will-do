# Will do

## 一、项目简介

**Will do 是一款 Android 智能信息记录助手**
通过截图、图片、文字等方式，识别日常生活中的各类信息，将日程安排、出行信息、取件码和账单自动整理并记录，配合提醒与实况通知，让信息从看到到记下更省事。

## 二、核心功能

### 信息提取与记录

- **日程安排**：提取时间、地点和事项，支持提醒、重复日程、归档及系统日历同步。
- **取件与取餐**：识别取件码、取餐码及相关地点，集中展示，方便随时查看。
- **出行信息**：识别火车、航班、打车等信息，提取班次、座位、检票口等关键内容。
- **账单记录**：识别金额、收支方向和交易时间，自动记账并提示重复，支持手动编辑、收支统计及账单导入导出。
- **自动记账**：支持无障碍页面采集、Xposed 支付消息采集，以及通知与短信正则识别。适配情况随应用版本和系统环境有所不同。

### 悬浮窗与随口记

- 通过悬浮窗快速输入信息、发起识别或查看记录。
- 支持文字、语音与图片随口记，随时保存临时事项和灵感；详情菜单支持分享与保存为 Markdown，有录音或图片时打包为 ZIP。
- 配合侧边栏、快捷磁贴等入口，减少应用间切换。
- 通过实况通知展示日程、取件和记账结果，适配部分厂商胶囊与超级岛。

### 课表

- 支持课程导入与管理，以及单双周、重复课程和调课。
- 课程与日程结合展示，方便统一查看当天安排。
- 支持课程提醒和桌面小组件。

### 天气

- 查看天气信息，支持定位或选择位置。
- 提供天气预警与风险提示。
- 支持天气实况通知，方便及时了解天气变化。

### WebDAV

- 连接自己的 WebDAV 服务，进行数据备份与同步。
- 支持本地备份与恢复，方便迁移和保存数据。

### 链接解析（实验功能）

实验室支持导入符合 [源协议](开发记录/链接解析源接口协议.md) 的单个 JS ZIP 解析源，可更换或移除。开启自动生成摘要后，新链接收藏可在后台提取素材、生成摘要，完成通知直达原随口记；默认使用本地音频转写，也可选择直接发送音频给已配置的在线 AI。转写原文单独保存，可选择按句号分段追加到正文，此选项默认关闭。平台登录入口由导入源声明，应用不预置具体平台；未声明登录入口的源仍可正常解析。

链接解析为实验功能，应用不内置或分发第三方平台解析源。仓库提供仅访问作者自有博客的教学示例。用户可自行导入符合协议的源，并应确保具有相应的访问和使用权限。不得用于未经授权的数据采集、传播或侵犯他人权益。生成摘要时，相关素材将发送至用户配置的 AI 服务。

想体验或自行编写解析源，可从 [博客示例与开发入门](开发记录/链接解析源开发指南.md) 开始，包含已真机生成摘要的示例、字段说明、六个离线返回案例、校验工具和编程 AI 任务模板。完整宿主接口见 [源协议](开发记录/链接解析源接口协议.md)。随口记升级的完整设计与取舍见 [开发记录 v86](开发记录/2026-10-08至2026-10-09-v86.md)。

## 三、安装与使用

**支持 Android 13 及以上版本。**

### 下载

[点击下载](https://github.com/AIXINJUELUOAI/Will-do/releases)

### 开始使用

1. 下载并安装 Release 页面提供的安装包。
2. 在“模型与连接”中配置模型服务；截图和图片识别需要支持图片输入的多模态模型。
3. 根据需要授予通知、日历、悬浮窗或无障碍等权限。
4. 通过应用内入口、悬浮窗或快捷磁贴开始识别与记录。
